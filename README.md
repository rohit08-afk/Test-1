Purpose
Provides visibility into supplier acknowledgement of readiness communications and highlights suppliers requiring follow-up.
What this indicator shows
• Overall supplier acknowledgement rate
• Acknowledged and outstanding supplier population
• Acknowledgement position by supplier priority
• Supporting supplier-level information for follow-up
How to use
• Review the overall acknowledgement position
• Use the detailed breakdown to identify outstanding suppliers
• Filter the population where required
• Review or export the supporting supplier list for follow-up
Note
Acknowledgement status reflects the latest communication outcome captured in the GL1 Supplier Integration Register.
