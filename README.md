The existing Supplier Readiness Tracker consolidates data from multiple approved project and enterprise sources, including:

- Smartsheets – Supplier Integration Registers and other readiness tracking data for GL1 and GL2
- Excel files hosted on SharePoint – supporting mappings, supplier/RO information, attendance data, and other project tracking inputs
- SharePoint Forms / Lists – project-created inputs used to capture and maintain readiness-related information
- SAP Business Network dashboard/data – supplier onboarding and enablement status
- Snowflake – supporting enterprise supplier and procurement data
- Ariba – supplier and procurement information used within the readiness process
- Supplier and RO session attendance files – webinar and onboarding attendance used for readiness reporting

These sources are already used by the existing Power BI dashboard. No new data source is being introduced as part of this request; the request is specifically for the appropriate access/licensing configuration to enable broader organizational sharing.
